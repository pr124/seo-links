## Fit and ambiguity notes

- **awesome remote mcp servers:** Owner is absent from the supplied name. jaw9c, punkpeye, and sylviangth each have a matching repository, so no unique URL is assigned. jaw9c's contribution guide requires official support, production readiness, maintenance and security.
- **awesome mcp list:** No owner is specified. MobinX's README and CONTRIBUTING were opened; it requires a real MCP server and a public GitHub repository. notedit's primary page and raw README could not be fetched, so that historical candidate is not verified.
- **awesome mcp lists:** collabnix has the clear exact plural slug match; the supplied name does not name an owner. README asks contributors to read the contribution guidelines before suggesting changes.
- **Stork:** Use the directory route: the current homepage promotes Stork Wire. The separate submission page currently describes a one-time paid listing; review terms before submitting.
- **AI Directories:** Correct domain is aidirectori.es with the www host. Distinguish its own catalog listing from its directory-submission service; no promised SEO outcome is endorsed.
- **Claude Code plugin directory:** The official GitHub directory points to publishing documentation. Current submissions use the developer portal, require an eligible account/role, and undergo review; use an actual plugin bundle or MCP connector.
- **Affiliate Watch:** Official indexed pages confirm the identity, but the homepage, Chinese homepage and a program page returned no readable content in the reader. Relevant to businesses with an affiliate program; the current submission route was not verified.
- **BotsFloor:** The historical source name is preserved while the current on-site brand is BotStash. The homepage has Submit Product; the /submit page failed in the reader, so current submission details remain unverified.
- **Chrome Web Store:** The storefront redirected to an unsupported-browser page in the reader; Google's official publishing documentation opened. Fit requires an installable extension and compliance with the store's publishing requirements.
- **Evernote:** Its core purpose is personal and team notes rather than company listings. Public indexing, discoverability and backlink value of a shared note were not verified.
- **GitHub Pages:** This publishes the owner's own site or documentation; it is distinct from an independent directory listing or editorial placement. Assess the actual page's public accessibility and relevance.
- **Launch Directories:** The author's list supplies no URL. LaunchDirectories and launch.cab both match the name; the intended destination remains unclear.
- **LibHunt:** Indexed primary pages confirm the identity and focus. Official about and search pages returned 403; current submission availability was not verified.
- **Next Gen Tools:** The author's list supplies no URL. nextgentools.co and NxGn Tools have readable primary pages; nextgentools.me timed out. The intended destination remains unclear.
- **Privacy Tools:** Suitable only when the product fits its privacy focus and criteria; no general self-serve startup listing was verified.
- **SEO Wins:** This is the source author's SEO strategies business. No public product-submission directory or ordinary backlink-listing route was verified.
- **StackShare:** Official tool and stack pages are indexed, but homepage and top-tools retrieval failed. Current submission and profile options remain unconfirmed.
- **StackSocial:** Official deal catalogue is indexed. Homepage and partner-contact retrieval failed, so current vendor partnership requirements were not verified.
- **There's an AI for That:** Its official product profile confirms the identity. Homepage and featured-submission pages blocked retrieval; current listing terms were not verified.
- **Wavel:** The directory is wavel.io, distinct from the wavel.ai video and voice product. Its listing route and current requirements need direct review.
- **WikiHow:** The official app page confirms its website. Website pages blocked retrieval, so current contribution eligibility and external-link rules could not be checked.
- **Wikipedia:** Its external-links guideline excludes links mainly intended to promote a website or sell products. It is unsuitable for routine promotional link submissions.
